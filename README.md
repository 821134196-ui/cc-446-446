# 酒店迷你吧补货与离店结算平台（匿名演示）

纯 Python 标准库实现（`http.server` + `sqlite3`），**零第三方依赖、无需安装**。
覆盖客房/商品/陈列上限/批次效期/入住订单/每日盘点/补货车/消费确认/免单原因/退房冻结，
客人与账单全部使用匿名演示数据。

## 一条命令启动

```bash
./run.sh            # 默认 http://127.0.0.1:8000
./run.sh --reset    # 重建演示数据
# 可选：MINIBAR_PORT=8080 ./run.sh
```

首次启动自动建库并载入样例：**在住**（201/203/204/301/302）、**待退冻结**（202/303）、
六类**争议复核**样例；同时启动进程内提醒任务（临期批次、在住未盘提醒）。

## 业务规则

- **入住快照**：入住即生成 `v0` 房内库存快照；每次接受的盘点生成新版本（`parent_version` 串链）。
- **盘点版本链**：提交必须带基准版本；旧版本（离线重传）**不得覆盖新快照**，
  单据记 `rejected_stale` 并自动开 `offline_resend` 复核。`idem_key` 支持离线重传去重。
- **消费形成**：盘点数量较快照减少 → 待确认消费；同时按陈列上限从补货车
  **FEFO（效期近者先出）**转入新批次，补货车不足开 `cart_shortage` 复核。
- **效期/破损**：已过期或包装破损批次**只能转报损（终态 writeoff），不能再次上架**；
  包装照片落本地 `data/photos/`。
- **退房冻结**：冻结锁定最后一次盘点，期间不能再盘点（转入 `post_checkout` 复核）；
  前台在所有消费确认/复核结案后才能确认账单、调用模拟结算通道并关闭订单释放房态。
- **六类复核**：客人否认、跨房放错、批次临期、补货车短缺、离线重传、退房后补录。
- **权限**：免单、账单冲销、跨房裁定、补录核准均需**经理权限并留存原因**；
  冲销与结算按 `idem_key` **幂等**，重复操作不产生第二行；员工按楼层隔离。

## 页面

楼层房态（按楼层的**紧凑列表**）、房内盘点（**商品图片 / 当前数 / 补货数 三列固定**）、
补货车清单、消费复核（**账单时间线**展开争议）、效期报损、退房结算（打印友好）。
配色为象牙白 `#FBF8F1`、藏青 `#1F2A44`、香槟金 `#C9A86A`；金额使用等宽数字对齐两位小数。

## 测试

```bash
python3 -m unittest discover -s minibar/tests -p "test_*.py"
```

27 个用例，覆盖要求的五项：版本冲突（旧版本不覆盖+离线幂等）、批次 FEFO
（补货/房内消耗/过期破损不参与/报损终态）、退房冻结（锁盘点、未决项阻止关单、补录走核准）、
冲销幂等（经理+原因、重复冲销一行、免单幂等）、楼层权限（2F↔3F 拒绝、列表按层过滤）。

## 目录

```
minibar/
  config.py        主题色、效期阈值、角色/复核类型/原因码表
  db.py            SQLite schema（快照版本链、批次、账单、复核、结算、提醒日志）
  services.py      领域服务（FEFO/盘点版本链/消费/复核/免单冲销/冻结结算）
  reminders.py     进程内守护线程：临期 + 未盘提醒（alert_log 去重）
  photos.py        包装照片本地落盘
  adapters.py      模拟 PMS 房态 + 模拟支付结算通道
  seed.py          匿名演示样例（在住/待退/六类复核）
  art.py           商品 SVG 占位图生成
  web/             HTTP 路由、表单（含 multipart）、页面渲染、打印样式
data/
  minibar.db       SQLite 数据库（运行时生成）
  photos/          包装照片目录
```
